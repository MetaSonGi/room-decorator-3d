# 🏠 3D 룸 데코레이터 (room-decorator-3d)

이미지로 3D 공간을 만들고, 가구 오브젝트로 꾸미고, 동선(워크스루 경로)과 사람 흐름 시뮬레이션까지 할 수 있는 웹앱.

## 기능

### 🖼 이미지로 공간 만들기
- 방 크기 조절 (가로/세로/높이 슬라이더, 3~12m)
- 이미지 업로드 → 벽지: 북/남/동/서 중 선택 or 전체 벽 적용 (반복 타일 / 꽉 채우기)
- 이미지 업로드 → 포스터/액자: 벽 선택 + 좌우/높이/너비 슬라이더 or 벽 직접 클릭으로 배치
- 바닥: 색상 선택 + 이미지 업로드(타일)

### 🪑 오브젝트로 꾸미기
- 로우폴리 가구 9종: 의자 / 테이블 / 소파 / 침대 / 플로어 스탠드(조명) / 화분 / 책장 / 러그 / TV
- 카탈로그 클릭 → 반투명 고스트 미리보기 → 바닥 클릭으로 배치
- 배치된 가구 클릭 선택 → 드래그 이동, 회전(슬라이더/버튼), 색상 변경, 삭제
- 조명: ambient + directional(그림자) 기본, 스탠드마다 PointLight (최대 4개)

### 🚶 동선 (워크스루 경로)
- 동선 모드 → 바닥 클릭으로 웨이포인트 추가 (번호 표시, 선 연결, 목록 관리)
- 투어 시작: 카메라가 눈높이(1.6m)로 경로를 따라 이동, 속도 조절, 일시정지/종료

### 🚶‍♂️ 사람 흐름 시뮬레이션
- 동선 경로를 따라 사람들이 걷는 애니메이션 (캡슐 몸통 + 머리, 랜덤 파스텔 색상)
- 사람 수 (1~20명), 걷기 속도 조절
- 시작/정지/리셋, 시뮬레이션 중에도 OrbitControls로 자유롭게 관찰 가능

### 공통
- OrbitControls (회전/줌/패닝), 탑뷰 버튼, 벽 표시 on/off
- 스크린샷 PNG 다운로드
- 저장/불러오기 (localStorage, 이미지 dataURL 포함 — 4MB 초과 시 이미지 제외)

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 바로 사용 가능.

⚠️ **인터넷 연결 필요**: 3D 렌더링에 Three.js를 CDN(`unpkg.com/three@0.160.0`)에서 불러옵니다. CDN이 차단된 환경에서는 안내 화면이 표시됩니다. 그 외 외부 의존성은 없습니다.

## 조작 요약

| 동작 | 방법 |
|---|---|
| 화면 회전/줌/이동 | 드래그 / 휠 / 우클릭 드래그 |
| 가구 배치 | 카탈로그 클릭 → 바닥 클릭 (ESC 취소) |
| 가구 이동 | 선택 후 드래그 |
| 가구 회전/색상/삭제 | 선택 후 좌측 패널 |
| 포스터 배치 | 이미지 선택 → 벽 클릭 or 배치 버튼 |
| 동선 그리기 | 동선 모드 → 바닥 클릭 |
| 투어 | 동선 2개 이상 → 투어 시작 |

이어폰/헤드폰은 필요 없습니다 (소리 없음). 😄
